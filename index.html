Workstreams are a display taxonomy derived from task IDs and source chapters; they are not a claim about module boundaries. Curves between workstreams summarize actual cross-stream dependencies. Zoom in or select a task to see individual edges. Dependency layers use the longest prerequisite path; arrows point from prerequisites to their consumers.

Replay shows task creation, active attempt intervals and the acceptance time of each task’s currently accepted result, on today’s dependency graph. Historical topology is not reconstructed. “Integrated” is the fleet’s task state, not a certificate that a fraction of CFSG is proved. Source counts are a working-tree inventory, not a Lean build or axiom audit. The site refreshes when a new snapshot is published.
